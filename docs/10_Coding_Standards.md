# 10 - Coding Standards

## Objectif

Les standards de code permettent de conserver un projet lisible, cohérent et facile à maintenir.

Tous les contributeurs doivent suivre les mêmes conventions.

---

## Principes

- Privilégier la simplicité.
- Écrire du code lisible.
- Éviter les duplications.
- Séparer les responsabilités.
- Utiliser des noms explicites.
- Ne pas ajouter de complexité sans besoin réel.

---

## TypeScript

TypeScript est obligatoire.

Les règles principales sont :

- éviter `any` ;
- typer les fonctions ;
- typer les props ;
- typer les retours ;
- utiliser des types explicites lorsque nécessaire ;
- centraliser les types partagés.
